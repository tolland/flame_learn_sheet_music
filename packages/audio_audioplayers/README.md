# Audio_audioplayers


This package wraps the audioplayers package:

* <https://github.com/bluefireteam/audioplayers/tree/main>
* <https://pub.dev/packages/audioplayers>

The audioplayers package supports all platforms, e.g. web, android, linux, windows. However the performance of the web implementation is low compared to soundpool.
